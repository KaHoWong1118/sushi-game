# Sushi for Pigeon 🍣🐦

A small browser game made by Ka Ho with ChatGPT. Toss salmon, shrimp, or tuna into a hungry pigeon's open beak and score as many points as you can in 60 seconds.

## Play

Download this repository and open `index.html` in a browser. The game is self-contained and needs no installation or external libraries.

- **Phone:** tap to aim and shoot.
- **Computer:** move the mouse to aim; click or press Space to shoot.
- **Sushi selection:** use the on-screen buttons or keys 1, 2, and 3.
- **Sound:** toggle the sound button.

## Features

- 3D-style canvas graphics
- Three sushi choices
- Timed rounds, score, and accuracy
- Touch and mouse controls
- Optional synthesized sound effects
